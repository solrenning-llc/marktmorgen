4 November 2026. The waiting-block command count is bounded by fourteen (two without pending items), rather than required to equal that count. Actual counts still enter each JSON profile; buyer visibility, product/room/provider checks and the whole-page financial ceiling are unchanged.

This branch is a diagnostic baseline, not an implementation or funding approval. It remains intentionally RED when the whole page exceeds its eighteen-command model. Do not open a product PR or claim MR approval from this measurement. The source remains the frozen baseline parent; a future bounded implementation requires a fresh whole-page measurement and cost proof, including provider calls and bytes. No prices, rights, limits, coefficients, flags, real accounts or deliveries change.
